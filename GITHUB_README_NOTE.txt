## Quick start
See `README.md` and `TEAMMATE_SETUP_GUIDE.md`.

1. MongoDB on port 27017
2. `cd server` → copy `.env.example` to `.env` → `npm install` → `npm run seed` → `npm run dev`
3. `cd client` → `npm install` → `npm run dev`
4. Open http://127.0.0.1:5173

## Notes
- Do **not** commit `.env` (secrets).
- `node_modules` is not included — run `npm install` after clone.
